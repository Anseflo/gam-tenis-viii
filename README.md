# Dashboard GAM Tenis VIII

Dashboard de solo lectura para GitHub Pages.

## Publicar
1. Crear repositorio público en GitHub.
2. Subir `index.html` y `data.js` a la raíz.
3. Settings → Pages → Deploy from a branch → main → / (root).
4. Compartir el enlace que genere GitHub Pages.

## Actualización de resultados
Los datos de esta versión son una **instantánea** de los cuatro archivos entregados. Para actualizar manualmente se debe regenerar `data.js` a partir de las hojas públicas y volver a subirlo.

Para actualización automática, crear una planilla Google Sheets **separada y pública** que contenga únicamente `Fase de grupos Serie A`, `Fase de grupos Serie B`, `Copas Serie A` y `Copas Serie B`; luego configurar una importación periódica desde esas pestañas. **Nunca publicar la planilla original** si contiene pestañas privadas.

## Privacidad
No se incluyeron ni consultaron las hojas `Gastos del campeonato` ni `Participantes`. Los nombres de jugadores de las tablas de posiciones son necesarios para el dashboard público.
